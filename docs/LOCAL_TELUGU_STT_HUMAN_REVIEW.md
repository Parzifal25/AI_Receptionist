synthetic clips at the 16 kHz model input and an emulated 8 kHz phone band.
This is a reproducible synthetic regression check, not a human-speech
evaluation. See `scripts/evaluate-local-synthetic-corpus.py` for the exact
normalization and scoring procedure; it writes no output files. It uses
sherpa-onnx 1.13.8, four threads, NFC/lowercase normalization, punctuation

lower-CER of the Latin and Telugu-script references. WER/CER are micro-averaged
edit counts over each group. Human sample count remains **0**.

రావచ్చా?` → Gujarati-script `રેપુ મી ટીમ રાવત છા` at 16 kHz and

human speech. The 8 kHz Tenglish score improvement on three clips is not
